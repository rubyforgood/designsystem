# Color

One brand colour, a neutral scale for surfaces and text, and four status colours that carry
meaning. Colour is never the only way something is shown: pair it with text or an icon.

## Brand

Primary actions, links, focus rings and selected states. Use the brand colour sparingly so it
keeps its meaning.

<ColorScale prefix="--color-brand-" />

## Neutral

Text, borders, backgrounds and surfaces. Body text is `neutral-700`, headings `neutral-900`,
borders `neutral-200`.

<ColorScale prefix="--color-neutral-" />

## Status

For success, warning, danger and information. Use them for status pills, callouts, flash
messages and validation, not for decoration.

<ColorScale prefix="--color-success" />

## Contrast

Text must meet WCAG 2.2 AA contrast: 4.5:1 for body text, 3:1 for large text and for the
edges of controls. The accessibility check on every story in this Storybook tests this.

## Theming

Override the token values to apply your own brand. Keep the names; change the values:

```css
:root {
  --color-brand-50: #f0fdfa;
  --color-brand-100: #ccfbf1;
  --color-brand-600: #0d9488;
  --color-brand-700: #0f766e;
}
```

Re-check contrast after changing colours.
